# Task Manager Backend (Node.js)

## 🚀 Overview
Backend API for Task Manager app built with Node.js, Express, and MongoDB. Provides authentication and task CRUD operations.

## 🔥 Features
- User Registration & Login (JWT)
- Create Task
- Get Tasks
- Update Task
- Delete Task
- Protected Routes

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT Authentication

```bash
